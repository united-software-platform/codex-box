# codex-box

Окружение для изолированного запуска Codex в Docker-контейнере.

- [Правила проекта](#правила-проекта)

## Установка

Команды перечисляет `make help`. Полная подготовка проекта — `make init`, затем заполнение `.env`
по `.env.example` и повторный `make init`.

## Правила проекта

Правила подключены из `CLAUDE.md` и каталога `rules/`.
